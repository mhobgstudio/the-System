# System (oldApps)

Gamified productivity system — web version. Vanilla JS + IndexedDB + Google OAuth.

## Quick Start

```bash
python3 -m http.server 8000
# Open http://localhost:8000
```

## Git Commands

```bash
git clone <repo-url>
cd oldApps/System
git pull
```

## Local Hosting

```bash
python3 -m http.server 8000
# Open index.html
```
